# Interview Prep — Next.js App

Minimal Next.js (App Router) + TypeScript + Tailwind app that displays HR interview questions from static JSON.

Getting started:

1. Install dependencies

```bash
npm install
```

2. Run the dev server

```bash
npm run dev
```

Project structure highlights:
- `app/` — Next.js App Router pages and layout
- `components/` — Reusable UI components
- `data/questions.json` — Static JSON question data
- `types/` — TypeScript types
